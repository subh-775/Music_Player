# Updates

The app checks GitHub for new versions, downloads one when you ask, and gives it to Android's installer. You confirm the install.

## How you find out

**A green dot next to Settings in the menu.** Tapping Settings then takes you straight to the update.

A new version also shows a notice once. Closing the notice does not hide the update. The dot stays until you install it or a newer version comes out.

## When it checks

- **When the app starts**, a few seconds in.
- **Each time you come back to the app.**

It checks at most once every 15 minutes.

## Installing

1. **Download.** You can leave the Settings screen while it downloads.
2. **Check.** The file is checked before it is installed. See below.
3. **Install.** Android asks you to confirm. The first time, it also asks to allow installs from this app.
4. The app restarts on the new version.

### What is checked

- **Where it came from.** The file must come over HTTPS from a GitHub address, including after any redirect.
- **That all of it arrived.** The file size must match the size GitHub reports. A download that was cut off is deleted, and you can try again.

<Danger title="Install over the old version">
  The in-app updater installs over the old version, which keeps your playlists, liked songs, history and settings.

  Uninstalling first deletes all of that, and it cannot be recovered. Downloads are safe either way.
</Danger>

## Turning it off

**Settings → Automatic updates.** When it is off, the app does not check in the background and no dot appears.

**Check for updates** still works when automatic updates are off.

## Version numbers

Versions look like `v1.2.9`. The number in **Settings → App version** always matches the release it came from. Versions are compared as numbers, so `v1.0.10` is newer than `v1.0.9`.

All versions and their notes are on **[the releases page](https://github.com/subh-775/Music_Player/releases)**.

## What an update keeps

| | |
| --- | --- |
| **Kept** | Playlists, liked songs, history, settings, equalizer, downloads |
| **May change** | Defaults for settings you never changed |
| **Never touched** | Files in your download folder |
