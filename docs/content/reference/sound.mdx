# Sound & Quality

Every setting that changes what you hear, and what it does.

## Streaming quality

| Setting | Bitrate | Data per hour |
| --- | --- | --- |
| **Auto** | The source's best | Varies |
| **Low** | 96 kbps | About 43 MB |
| **Normal** | 128 kbps | About 58 MB |
| **High** | 256 kbps | About 115 MB |
| **Very High** | 320 kbps | About 144 MB |

The setting is an **upper limit**. Asking for 320 does not turn a 128 kbps source into 320. You get that source's best, and the label under the song name shows what you got.

| Source | What it usually sends |
| --- | --- |
| **JioSaavn** | 320, 160 or 96 kbps, whichever file is really playing |
| **YouTube** | About 130 kbps |
| **SoundCloud** | 128 kbps |

If a source does not report a bitrate, there is no label.

<Note>
  On mobile data, **Normal** is a good choice. On phone speakers or cheap earbuds, 128 and 320 sound very close. The data use does not.
</Note>

## Crossfade

Fades the end of one song into the start of the next, for 0 to 12 seconds. 0 is off, which suits albums where songs run straight into each other.

Both songs play at once during the fade: one gets quieter while the other gets louder.

It works on **every automatic change** from one song to the next, from an album, a playlist, search or Autoplay, **with the screen on or off**.

It does not apply when:

- You press **next** or **previous**. You chose the song, so it changes right away.
- **Repeat this song** is on. A song fading into itself would just play twice at once.
- The sleep timer is set to **end of track**. The next song would start under the one you meant to fall asleep to.

### When it does not fade

The next song starts loading about 20 seconds early. If it is still not ready at the end of the current song, for example on a slow connection, **the songs change without a fade**. A fade into silence would sound like a drop in volume.

Downloaded songs open instantly, so they always fade.

## Normalize volume

Plays every song at about the same loudness, so a quiet old recording and a loud new one sit at a similar level.

- It works right away, on the song that is playing.
- It uses no effect at all when it is off.
- It changes the volume, not the recording. A quiet song gets louder, not clearer.

## Equalizer

Eight bands, ±12 dB, mapped onto your phone's own bands. See **[Equalizer](/guide/equalizer)**.

## Output devices

When headphones or a speaker are connected, the app shows a green headphones icon and the device name, in the mini player and the full player. If no sound comes from your phone, check this first.

## What the app does not do

- **No upscaling.** A 128 kbps stream stays 128 kbps.
- **No "hi-res" label.** The label shows the real bitrate.
- **No extra loudness.** Normalize brings quiet songs up. It does not push everything to the maximum.

## Bluetooth codecs

Android, not the app, picks the Bluetooth codec (SBC, AAC, aptX or LDAC). You can see it in **Developer options → Bluetooth audio codec**. A codec that sounds bad here sounds bad in every app.
