# Installation

Relaxify is published on GitHub, not the Play Store. Android asks once for permission to install it.

## 1. Download the file

On your phone, open **[the latest release](https://github.com/subh-775/Relaxify/releases/latest)** and download `Relaxify.apk`.

You can also download it on a computer and copy it to the phone. There is only one file.

<Note title="64-bit phones only">
  The app is built for **arm64-v8a**, which covers almost every Android phone from the last ten years. Old 32-bit phones (`armeabi-v7a`), x86 Chromebooks and most emulators cannot install it. Android will refuse the file.

  The app includes a full Python runtime. Adding a second build type would nearly double the download size.
</Note>

## 2. Allow the install

Tap the downloaded file. The first time, Android says your browser or file manager is not allowed to install apps.

Follow the prompt to **Settings → Install unknown apps**, turn it on for that one app (your browser, or Files), then go back. The install continues.

<Note>
  This permission is for **the app that opens the file**, not for Relaxify. You can turn it off again afterwards. The installed app keeps working.
</Note>

## 3. First launch

The first start takes a few seconds longer than later ones. The built-in engine unpacks itself, and the app restores what was playing last.

The splash screen stays until the engine and the home screen are both ready.

<Tip>
  You do not need to set anything up. Autoplay is on, quality is on Auto and the equalizer is off. See **[Quick Start](/guide/quick-start)**.
</Tip>

## Requirements

| | |
| --- | --- |
| **Android** | 8.0 (Oreo) or newer |
| **Storage** | About 120 MB for the app, plus your downloads |
| **Connection** | Needed to search and stream. Downloads play without one |
| **Account** | None |

## Permissions

Nothing is asked at install time. Each permission is asked the first time it is needed.

| Permission | Asked when | If you say no |
| --- | --- | --- |
| **Notifications** | You first play a song | Music still plays. You lose the lock screen and notification controls |
| **Storage** | You first download a song | Streaming still works. Downloads cannot be saved |
| **Install apps** | An update is ready | In-app updates stop. You can still install a new version by hand |

## Updating

The app checks for new versions and can install them from Settings. You do not repeat the steps above.

<Danger title="Never uninstall to update">
  Install the new version **over** the old one. Uninstalling deletes your playlists, liked songs and history, and Android cannot get them back. The in-app updater always installs over the old version.

  Your **downloads** are safe either way. They are in your own music folder, not in the app's storage.
</Danger>

See **[Updates](/reference/updates)**.
